# Hisense TV CN MT9655 / Emby 1.8.5

面向中國大陸版 MediaTek MT9655 Hisense TV；目前僅海信 UXS 實測，不宣稱所有海信型號適配。

同一個脫敏 APK 支援官方 Emby Android 通用版與 Android TV 版。兩版可共存；在推薦海報設定中選擇播放應用，首頁入口、帳號同步與續播跟隨選擇。Android TV 使用直接續播、正常 Back 與原生續播備援；通用版保留已有流程。
