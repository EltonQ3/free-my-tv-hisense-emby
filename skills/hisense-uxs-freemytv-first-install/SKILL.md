# Free My TV · Hisense TV CN MT9655 / Emby：首次安裝

本改版面向中國大陸版、搭載 MediaTek MT9655 的 Hisense TV；目前僅測試海信 UXS 可用性。其他 MT9655 型號、其他晶片、其他地區版本及韌體未驗證，不能視為所有海信電視均已適配。

協助第一次使用的人安裝 **1.8.5 脫敏版**，完成基本桌面後，再按需要設定 Emby 海報、TMDB 和聚好看按需啟用。用簡單中文說明目前要做的事；電視上的授權、密碼和 PIN 由使用者操作。

本 skill 配套檔案為 `FreeMyTV-UXS-1.8.5-20261026-Public.zip`。這是非官方桌面應用，不是電視韌體；不需要既有私人恢復包、舊安裝紀錄或其他人的設定。

## 一、確認對象與準備

優先從可用環境辨識電腦系統及已備工具，再取得缺少的資訊：電視型號／Android 版本、電視目前的區域網路 IPv4 位址，以及使用者是否需要 Emby。城市、片庫地址和金鑰不是基本安裝前提，暫時沒有可先完成桌面。

參考適配機為海信 UXS、MT9655、Android 14。其他系統先確認相容性；非 Android 電視不能直接安裝 APK。參考機已有工廠 M 模式調試與使用者確認的 U 模式日常使用經驗；其他機型與韌體仍需另行確認。安裝過程不自動改工廠模式、音畫、HDR、CEC、校準、網路或原版播放器帳號。

準備：

- 電視、實體遙控器，以及與電視可互通的電腦；訪客網路的裝置隔離可能阻止連線。
- 完整解壓的 Public ZIP 和 **Python 3.9 或更新版本**。
- Mac：包內已有官方 macOS 版 adb。Windows／Linux：先安裝 Google 官方 Android SDK Platform-Tools，讓 `adb` 可從終端執行；Python 腳本會使用它。需要時以 `FREEMYTV_ADB` 指定其完整路徑。

直接安裝現成 APK，**不需要 JDK、Android SDK 編譯平台、Gradle 或重新編譯**。僅在工具缺少時補裝；不要為第一次安裝順便修改原始碼。

## 二、核對安裝包

這個 Public 包沒有預設 Emby 伺服器、帳號、金鑰、城市或位置；天氣預設關閉。Emby 是初始推薦來源，但尚未連接片庫；TMDB 地區預設 HK。包內不含 Emby 等第三方 App APK。

固定版本資料：

- 套件：`io.freemytv`
- 版本：`1.8.5-uxs.20261026-public`；versionCode `38`
- Public ZIP SHA-256：以同版 `Public-SHA256SUMS.txt` 為準。
- `FreeMyTV.apk` SHA-256：須同時符合 `version.json` 與同版 `Public-SHA256SUMS.txt`。
- APK 簽名憑證 SHA-256：`e9271d5ef1ea9a85bcb9b1d25a6029d74d0c68679bf8d3da7a6c5d66a90ea03e`

先比對下載 ZIP 的雜湊，再在解壓資料夾執行：

```sh
python3 tools/restore.py --check
```

Windows 若只有 `python` 或 `py -3`，使用對應的 Python 3.9+ 指令。此步只做離線校驗，不操作電視。核對 `version.json`、`SHA256SUMS.txt` 和 `安裝說明.txt`；校驗失敗就重新取得完整檔案，不跳過檢查。

## 三、在電視開啟初次調試

1. 在電視的網路資訊頁找出**目前 IP**，不要沿用他人的地址。
2. 在電視系統設定開啟**開發者模式／開發者選項**及 **USB 調試**。入口隨海信韌體不同；若找不到，先確認該機的實際選單或韌體說明，不猜工廠菜單密碼、連按組合或要求切換 M／U 模式。
3. 參考韌體在 USB 調試開啟時即可使用 TCP `5555`，不必同時開 Android「無線調試」。其他韌體依實際提供的連線方式判斷，不寫持久 TCP 屬性來強行開通。

說明接下來會安裝桌面，並由使用者在應用內選定新首頁及屏保。原廠應用與輸入服務保留；聚好看「按需啟用」另在後面選擇，不作為初次安裝的前置條件。

## 四、安裝 APK

**優先使用附帶工具：** Mac 雙擊「安裝桌面.command」，或在解壓資料夾執行 `python3 tools/restore.py`。工具會詢問電視 IP，校驗後覆蓋安裝，最後打開 Free My TV 設定。

第一次連線，電視會彈出「允許 USB 調試」：讓使用者選允許，可勾選一律允許此電腦。若工具已停止，授權後重新執行即可。

工具另問是否授予首頁調試按鈕 `WRITE_SECURE_SETTINGS`：說明此系統權限定義較廣，本版按鈕只切換開發者模式和 USB 調試，讓安裝者決定。拒絕也能使用桌面，只需從系統設定手動管理調試。沿用本次安裝對話已有的明確授權，不重複要求同一授權。

需要人工操作時，依次執行以下命令；先把 `<TV_IP>` 換成當前電視地址，逐項檢查結果，不能把占位符原樣執行。Mac 可使用包內 `tools/adb`：

```sh
adb connect <TV_IP>:5555
adb devices
adb install --no-incremental -r FreeMyTV.apk
adb shell am start -n io.freemytv/.SettingsActivity
```

授權首頁調試按鈕時另執行：

```sh
adb shell pm grant io.freemytv android.permission.WRITE_SECURE_SETTINGS
```

確認安裝回覆 Success，版本和套件相符，權限如已申請則核對 granted=true。安裝失敗、簽名不符或版本降級時先查明原因，不自動卸載、清資料或添加降級參數。若發現早已有同名 App，把它當成更新情況處理；脫敏包不會清除舊 App 資料。

## 五、選定首頁及無障礙服務

1. 在電視打開 Free My TV；一般應用圖示會進入設定頁。
2. 設定主頁 → **主屏幕 → Free My TV**，等應用完成切換。
3. 若電視再次要求「允許 USB 調試」，這次是**桌面自身的本機連線**，與電腦授權不同；讓使用者允許並可勾選一律允許。
4. 系統無障礙設定中開啟 **Free My TV**，供 Home／遙控按鈕處理。服務名稱對應 `io.freemytv/.RemoteKeyService`。
5. 若要使用 TV 版海報續播，或需要自動切換任何一版播放器帳號，再開啟 **Emby 账号遥控**，對應 `.EmbyAccountService`。這項服務會操作原版 Emby 介面；密碼／PIN 仍手動輸入。
6. 保留所有其他原有無障礙服務。若 Android 提示受限制設定，按該機提供的官方應用授權介面處理；不要透過改寫整份服務清單繞過提示。

先完成基本驗證：新桌面可見；打開一個普通 App，再按**實體遙控器 Home**，能回 Free My TV；設定頁可重新打開。不能僅憑電腦模擬 Home 就宣稱實體按鍵正常。

此版本採**單首頁**：Home 從其他 App、聚好看或 HDMI 回 Free My TV；聚好看仍可由應用入口主動開啟。若按鍵不符合預期，先檢查模式切換結果、無障礙服務及實際韌體，不直接停用更多系統套件。

## 六、可選：連接 Emby 海報和續播

沒有 Emby 的人可略過。安裝包不提供伺服器、影片或第三方播放器 APK。另從[官方下載頁](https://emby.media/emby-for-android.html)安裝 **Emby Android 通用版**（`com.mb.android`）或[官方 Emby Android TV](https://emby.media/emby-for-android-tv.html)（`tv.emby.embyatv`），並正常登入自己的伺服器與帳號。兩版可同時保留。

在 **推荐海报设置 → Emby → 播放应用** 選擇要用的版本；未選時優先 TV 版，再選已安裝的通用版。首頁卡片、海報播放與帳號同步都跟隨此選擇。參考版本為通用版 **3.5.35**、TV 版 **2.5.03g**；不代表目前最新版或所有新版介面均實測。

**TV 直接續播的可選授權：** 安裝工具會另外詢問是否授予 `DUMP`。說明它可讀取較廣的系統狀態，本程式只解析 Emby／自身的窗口任務與程序身份，不保留或上傳完整傾印。先沿用安裝對話已有的明確授權；未獲授權不執行以下命令。通用版不需要 DUMP，TV 版拒絕此權限仍可走 Emby 的原生續播按鈕。

```sh
adb shell pm grant io.freemytv android.permission.DUMP
```

此為一次性權限；平常關閉開發者／USB 調試後仍可使用。Android TV 的直接續播需要「Emby 账号遥控」服務核對原生畫面；如不使用此服務，保留正常手動打開播放器的方式。若先用過未授權的 TV 原生續播，再補授權，可在使用者同意時重啟電視一次，讓程式以乾淨連線啟用直接續播；不要用反覆開啟啟動頁的方式強行測試。

本版會按套件、安裝版本、裝置及帳號識別播放器，不因安裝了另一版就停用或刪除它；版本相同而不能分辨、或有多個同樣身份的連線時，停止自動交接並讓使用者核對版本及登入狀態。

請使用者備妥自己的伺服器 URL 和 API 金鑰。自管伺服器可在 Emby 管理後台建立；若無管理權限，向伺服器提供者取得可用設定，不讀取或破解播放器的私人登入資料。金鑰不要貼進聊天。

電視輸入方式：**Free My TV 設定主頁 → 推荐海报设置 → Emby**，填地址和金鑰、驗證後選 Emby 帳號。

較方便的電腦輸入方式：

1. 保持調試連線，先離開電視的 Emby 設定頁。
2. Mac 執行「電腦設定Emby.command」；其他平台在解壓資料夾執行 `python3 tools/restore.py --emby`。
3. 讓使用者在自動打開的本機頁輸入伺服器 URL、API 金鑰和**準確的 Emby 帳號名稱**。
4. 頁面只監聽 `127.0.0.1`，使用隨機一次性地址，15 分鐘失效；電腦在記憶體處理，驗證請求送到指定 Emby 伺服器，再將設定寫入電視的應用私有儲存。
5. 看到已儲存後關閉網頁，回到設定檢查連線與所選帳號，再進首頁。如舊海報未更新，重新打開 Free My TV。
6. **推荐海报设置 → 来源 → Emby**；若尚未開啟且需要自動切播放器帳號，完成上一節的「Emby 账号遥控」授權。

內網 HTTP 只支援經驗證的私有地址；外網使用有效 HTTPS。若電腦能驗證、電視卻不能載入，分別核對兩者到伺服器的網路可達性；不要改成全域允許明文或略過憑證驗證。

首頁的 Emby 帳號下拉選單會讀取原色頭像；推薦按目前用戶組織為繼續播放、推薦、新到電影、新上劇。點選劇集按該用戶觀看進度決定續播對象，並傳遞起播位置。播放器需正常登入且介面可操作；遇密碼／PIN 或切換失敗時停在可由使用者完成的畫面，不假報切換成功。

需要驗收時先核對所選播放器與首頁帳號：從一部已有進度的影片開始，確認起播位置；按 Back 應退出播放並回原生片頁，不能再次播放。TV 直接路徑只發送一次播放；完全退出後若有舊程序殘留，會在發送之前改選原生續播按鈕，不在不確定的播放回應後重試。不要把「安裝成功」等同於完成播放驗收。

推薦停留每 30 分鐘同步，返回首頁也會更新；焦點不在海報且空閒 10 秒時換分頁。不是每次都要重新執行電腦工具。需要驗證續播時，讓使用者選一部已有進度的影片確認；不擅自改動進度或標記看過。

## 七、可選：TMDB、主題和其他偏好

只使用 Emby 推薦不需要申請 TMDB 金鑰。想使用 TMDB 時，由使用者用自己的帳號申請金鑰，在 **推荐海报设置 → TMDB** 設定金鑰及片庫地區，再到 **来源 → TMDB** 選用。

長金鑰可用「電腦設定TMDB.command」，或 `python3 tools/restore.py --tmdb`。使用者在本機頁輸入，工具經 ADB 輸入資料傳送，電視以 Android Keystore 加密儲存；不放在命令列參數或公開檔案裡。匯入只確認已儲存，想檢查外網連線時再由 TMDB 設定頁選「連線測試」。若韌體拒絕匯入權限，改用電視設定頁，不繞過系統限制。

常用入口均位於設定主頁：

- **主题设置**：Chiikawa、經典、Fate 誓約、Fate 暮光、Lucy 夜之城、魔法使之夜六種設定頁美術，按個人喜好選擇。
- **主屏幕设置**：首頁明暗、導航音效、城市／天氣、股票指數、**屏幕保护等待时间**。屏保預設 1 分鐘，可選 1／2／5／10／15／30 分鐘，只計算首頁空閒。
- **顶部按钮**：選擇調試、Emby 帳號或電視直播等入口是否顯示。調試開啟只亮內部深綠，關閉灰白；下方快捷方式同樣可切換。

新安裝的設定頁美術預設為 Chiikawa；可自行選擇其他主題。六種主題包括 Chiikawa、經典、Fate 誓約、Fate 暮光、Lucy 夜之城及魔法使之夜；主題面板與首頁應用卡片已內建相應的顯示樣式，無需額外開啟畫質選項。

設定頁美術與首頁明暗主題是兩個選項。天氣預設關閉，先設定自己的城市後再按需開啟；不要填入別人的位置。

## 八、可選：聚好看按需啟用

完成基本首頁與 Home 驗證後，再讓使用者決定是否使用此功能。入口：**設定主頁 → 主屏幕设置 → 聚好看 → 按需启用**。全新安裝不會自動啟用。

說明效果：只管理 `com.jamdeo.tv.vod`，平常停用並強停，從卡片或設定主動開啟時放出，回到 Free 並確認可見後再封鎖；保留原廠應用及資料。「始终可用」取消此按需封鎖，不改變單首頁邏輯。

若使用者選擇啟用，驗證一次卡片開啟聚好看 → 實體 Home 回 Free → 聚好看重新封鎖。調試關閉時點卡片，提示窗可開啟開發者＋USB 調試後繼續。首頁按鈕不開關獨立的無線調試設定。

最後按使用者意願測試調試關閉／重開。關閉會中斷電腦連線，先說明並準備好實體遙控操作；不把失聯誤判成 App 崩潰。封鎖失敗時如實回報，保留可用狀態，不批量停用 HDMI、直播、系統設定或工廠服務。

## 九、完成標準與常見卡點

完成時用短清單交代：已安裝的版本、新首頁是否啟用、實體 Home 是否正常、已配置哪個推薦來源、哪些可選項略過，以及下一次如何進入設定。只回報實際驗證過的結果。

- **找不到電視／連線被拒絕**：核對當前 IP、同網路互通、USB 調試及電視授權。顯示 unauthorized 時在電視允許後重試；不要清除全部調試配對。
- **Mac 顯示 No route to host**：若電視 TCP 5555 實際可達，核對執行程式的 macOS 本機網路權限；可在使用者互動終端前景執行 `adb nodaemon server`。不要無故終止其他使用者的 adb 工作。
- **Home 仍回聚好看**：核對應用內主屏幕模式及「Free My TV」無障礙服務，再用實體 Home 重試；不要用卸載原廠首頁處理。
- **沒有海報**：先確認推薦來源，再核對電視到對應服務的連線及自己的金鑰／帳號。空白 Emby 設定不是安裝失敗，TMDB 也不是 Emby 的必需條件。
- **播放器帳號或續播不對**：核對首頁與播放器帳號、無障礙服務、密碼／PIN 及播放器版本；不讀取其私人資料庫，也不把失敗隱藏成成功。
- **想退回原版**：先開調試，在 Free My TV 設定 → **主屏幕 → 原版** 完成還原，確認聚好看可用，再決定卸載。只點聚好看卡片不等於完整還原。若應用無法操作且有授權 ADB，可先窄範圍執行 `adb shell pm enable --user 0 com.jamdeo.tv.vod`，核對原廠入口；不清資料或盲目清除恢復紀錄。

同一失敗在確認前提後仍重現時，保留原可用桌面，記錄必要的非敏感錯誤再定位，不輪流猜測危險系統設定。避免完整輸出活動傾印、片庫、觀看進度或金鑰；測試 Home／帳號時避免 `uiautomator dump` 暫時壓掉無障礙服務。
