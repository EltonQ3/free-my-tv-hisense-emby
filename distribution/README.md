# Installer sources

These are the reviewed helper sources used by the Public ZIP. Download and fully extract the Release ZIP to run them: it supplies the APK, complete manifests and official macOS adb. This folder alone is not an installation bundle. Windows/Linux use their own official Android platform-tools.

The installer does not uninstall, downgrade or clear existing data on signature/version failures. Long credentials use one-use loopback forms and stdin delivery, not command-line arguments.
